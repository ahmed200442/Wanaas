## ✨ مميزات التطبيق

1. **تسجيل حساب جديد ودخول تلقائي (Auto-Login) مربوط بـ Supabase**:
   - تسجيل بالاسم أو اللقب، البريد الإلكتروني، كلمة المرور، وتأكيد كلمة المرور.
   - حفظ بيانات الحساب للدخول التلقائي فور فتح التطبيق دون الحاجة لإعادة كتابتها.
2. **غرف الدردشة المباشرة وإشعارات الدخول والخروج**:
   - ظهور بانر تلقائي **«دخل العضو فلان»** عند دخول الغرفة ويختفي تلقائياً، و**«خرج العضو فلان»** عند المغادرة.
   - عرض قائمة مباشرة للأعضاء المتواجدين حالياً داخل الغرفة.
3. **قسم «فضفضة بدون اسم» مع حماية الخصوصية وصلاحية الأدمن**:
   - نشر فضفضة عامة تظهر لجميع الأعضاء بدون أي اسم أو بريد إلكتروني.
   - يظهر الاسم الحقيقي والبريد الإلكتروني لصاحب الفضفضة **فقط للأدمن صاحب التطبيق** (`hamadanagy1979@gmail.com`).
4. **الإشعارات الفورية (Push Notifications)**:
   - تنبيهات فورية في شريط إشعارات الهاتف وداخل التطبيق عند تلقي رسالة جديدة أو دعوة صديق للانضمام إلى غرفة دردشة.
5. **بوابة الدفع الحقيقي وتفعيل باقات VIP**:
   - إيقاف التفعيل المجاني عند الضغط؛ يتطلب تفعيل باقات VIP التحقق الفعلي من بيانات البطاقة البنكية (16 رقماً عبر خوارزمية Luhn + تاريخ الانتهاء + CVV) أو التحقق من رقم محفظة فودافون كاش / إنستا باي ورقم مرجع التحويل، مع إصدار إيصال دفع موثق.
6. **الملف الشخصي والإحصائيات وسجل الدردشة**:
   - تعديل الاسم، اختيار صورة رمزية مخصصة من الهاتف أو رابط، ومتابعة إحصائيات النشاط وسجل الرسائل والغرف.
7. **تصميم عصري بالوضع النهاري والليلي**:
   - تباين ألوان غامقة وفاتحة مريحة للعين في الوضع النهاري والوضع الليلي.
